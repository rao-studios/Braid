Why a state, and not attention?

On Mamba2's scan, and why a history of fixed size is the right shape for provenance.

Under every step · the inference trail

A transformer remembers a conversation by keeping every token's keys and values, its KV cache, and the cache grows with every token. Mamba2 remembers differently. Each block carries a state of fixed size, and every new token updates it.

Per layer the state is a grid of 24 × 64 × 128 numbers, plus the last three inputs of a short convolution. Across 24 layers, the head's twelve and the commons' twelve, that is 19,390,464 bytes per strand, at the tenth token or the ten-thousandth. The weights are shared; the state is not.

One block

Each block reads the stream, projects it, runs a short convolution, and then scans. The state decays a little, takes in the new token, and is read out. That scan sits where attention would sit.

There is no attention anywhere in Braid, and no KV cache. A test fails if either appears.

Why provenance wants a state

A state of fixed size can be reset, saved, hashed and handed over. Braid does all four.

It resets at every record, so a record is read from a blank state in training, in the index and at inference alike. That is what lets a key written when the index was built match the key a session computes today.

It can be saved at checkpoints and replayed. Any key in an index can be recomputed from the nearest checkpoint, and braid verify --keys does exactly that for every cited key.

And it can be handed over. A Thread joining mid-answer catches up in one pass and matches one that was there from the start to within a ten-thousandth. A Thread detached and restored from its saved state continues with the same final state at every token. A Thread's machine needs only its head, its index and its state; the tail it runs can stay with the commons. The node protocol is built on that, ready for a wire that isn't built yet.

For model engineers: the scan, the state, the numbers

Braid writes its own scan. SSD.scan runs a sequence in chunks of 256 with no eval inside, so it traces under valueAndGrad and trains; Frigate's scan and its Metal kernel cannot. A resets mask zeroes the state and the convolution window at document starts. SSD.step is the same arithmetic for one token in plain MLX ops.
