The code explorer

On reading the code beside the tour: every Swift file whole, and four trails through the functions that run them.

Every Swift file under Sources/ is here, whole, with the line numbers Xcode shows. Pick a file, or walk one of four trails function by function: training, inference, and the same two for questions. Paste a function name, a signature or a whole body from Xcode, and the page opens that declaration with what it calls and what calls it. Those lists were matched by name when the site was built, not by a compiler, so each says how sure it is. Copy a line as File.swift:61 and Open Quickly lands on the same line.
